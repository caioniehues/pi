# Slice C9: built-in tools

Read first: `rust/docs/conventions.md`, `rust/docs/slices.md`, `pi-sdk::Tool` (C6a), `pi-core::config` (C7).
TS references, read in full: `packages/coding-agent/src/core/tools/*.ts` (every file, renderers excluded: they are
C17), `core/bash-executor.ts`, `utils/{shell,tools-manager,output-files,ansi,child-process,mime,paths}.ts`,
`docs/tools.md` if present and the tool sections of `docs/extensions.md` ("Overriding Built-in Tools",
"Remote Execution", "Output Truncation"), `packages/coding-agent/test/{tools,read-*,bash-*,edit-*,write-*,grep-*,find-*,ls-*,powershell-*,truncate-*,file-mutation-queue,path-utils,paths,shell-*,tools-manager,tool-system-prompt-contributions,output-pad}.test.ts`
and `test/suite/regressions/{3302-find-path-glob,3303-find-nested-gitignore,5208-late-bash-output,5303-bash-output-truncation,11613-bash-timeout-after-shell-exit}.test.ts`.

## Goal

`read`, `bash`, `powershell`, `edit`, `write`, `grep`, `find`, `ls` as `pi_sdk::Tool` implementations with the
same schemas, outputs, truncation, details and system-prompt contributions, plus the pluggable operations
interfaces extensions use to redirect them (SSH, containers).

## Deliverables (`pi-core/src/tools/`)

- `mod.rs`: `ToolName`, `all_tool_names`, `ToolsOptions`, `create_tool_definition(name, cwd, options)`,
  `create_coding_tool_definitions`, `create_read_only_tool_definitions`, `create_all_tool_definitions`.
- One file per tool with its schema (built with `pi-schema` builders, identical JSON to the TypeBox schema: a
  test compares against the JSON the TS emits, captured once into `rust/fixtures/tools/schemas/<tool>.json` by a
  node script), its `Operations` trait (`ReadOperations`, `BashOperations` with `BashSpawnHook`, `EditOperations`,
  `WriteOperations`, `GrepOperations`, `FindOperations`, `LsOperations`) with the local implementations, the
  details struct, the output schema where TS has one (`read`, `bash`), the system-prompt contribution.
- `bash.rs`: local shell operations (`get_shell_config` with the same detection order, login shell, `--norc`
  handling, the command written to stdin as TS does, process group, `kill_process_tree`, timeout, output
  accumulation with `OutputAccumulator`, spill of full output to a temp file through `output_files.rs` with mode
  0600, the `truncated`/`fullOutputPath` details, `exitCode` in `structuredContent`), `powershell.rs` on the same
  code with `POWERSHELL_ARGS` and the Windows config (compile on all platforms, run only where `pwsh`/`powershell`
  exists).
- `read.rs`: text with line ranges and the exact "(line range display)" formatting, binary and image handling
  (image bytes returned as an `ImageContent`; resizing is C23: until then return the file as is and note it),
  streaming updates, truncation.
- `edit.rs` + `edit_diff.rs`: `normalize_to_lf`, fuzzy matching (`fuzzy_find_text` with the same normalization and
  window rules), `apply_edits_to_normalized_content`, `generate_unified_patch` and `generate_diff_string` with
  `similar`, matching the TS diff output format exactly (goldens), legacy input shapes, diff-before-write.
- `write.rs`, `ls.rs`, `grep.rs` (runs `rg` with the same arguments, parses its output the same way,
  `GREP_MAX_LINE_LENGTH`), `find.rs` (runs `fd` with the same arguments, `relativize_find_result_path`, glob and
  nested-gitignore behaviour), `truncate.rs` (`truncate_head`, `truncate_tail`, `truncate_line`, `slice_head`,
  `slice_tail`, `format_size`, surrogate-safe slicing: Rust strings are UTF-8, so port the rules in terms of UTF-16
  units where TS counts UTF-16 units, and say so), `output_accumulator.rs`, `file_mutation_queue.rs`,
  `path_utils.rs`.
- `tools_manager.rs`: `get_tool_path("fd" | "rg")` resolving `<agentDir>/bin` first, then PATH; download of the
  pinned fd and ripgrep releases from GitHub into `<agentDir>/bin` with the same version pins, archive handling
  (`zip`/`tar.gz`) and `ToolStatus`; network only when the binary is missing, never in tests (tests use a fake
  release server or skip).
- `bash_executor.rs`: the user `!command` executor (`BashExecutor`, `BashResult`, streaming chunks, cancel).
- `shell.rs`, `child_process.rs`, `output_files.rs`, `ansi.rs` (`strip_ansi`, `split_incomplete_ansi_suffix`).

## Acceptance

- Every test listed above ported case by case (renderer tests excluded); Windows-only tests compile and are
  `#[cfg(windows)]`.
- Output goldens: for a fixed workspace under `rust/fixtures/tools/workspace/`, a node script runs each TS tool
  (through `createTool`) on 30 scripted calls and records `{ tool, args, result }`; the Rust tools produce equal
  `content`, `details` and `structuredContent` (temp paths normalized). Commit script and goldens.
- `grep`/`find` tests run only when `rg`/`fd` are on PATH or in the agent bin dir; they are skipped with a message
  otherwise, never downloaded during tests.
