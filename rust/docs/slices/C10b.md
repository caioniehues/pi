## Goal

The rest of the session core so that every RPC command of C12 has an implementation.

## Deliverables

- `agent_session/tree.rs`: `navigate_tree` with the `session_before_tree`/`session_tree` hooks, branch summaries
  (the summarization call lives in C11; here the flow and the entry writes), `get_user_messages_for_forking`,
  fork and clone through the runtime.
- `agent_session/models.rs`: model and thinking-level selection with `model_select`/`thinking_level_select`
  events, `ModelMutationOptions` (persisting defaults vs session-only), scoped models cycling, availability
  checks, `_refresh_current_model_from_registry`, provider registration and virtual-model registration applied
  to the `ModelRuntime`, `routed_model`; `virtual_models.rs` routing state persisted as `pi.virtual-model-state`
  custom entries.
- `agent_session/bash.rs`: `execute_bash`, `record_bash_result`, `abort_bash`, pending bash messages flushed into
  the transcript as `bashExecution` messages with `excludeFromContext`.
- `agent_session/stats.rs`: `get_session_stats` (`usage_totals.rs`, `cache_stats.rs`), `get_context_usage`,
  `get_last_assistant_text`, `export_to_jsonl`, `set_session_name` with `session_info_changed`.
- `cache_warmer.rs`: the cache warmer and its `cache_warming_decision` hook, `set_cache_warming_mode`,
  `cache_warming_status`, usage entries of kind `cache_warm`.
- `footer_data_provider.rs`: `find_git_paths`, branch and worktree detection, extension statuses.
