# Slice C8: session manager

Read first: `rust/docs/conventions.md`, `rust/docs/slices.md`, `pi-types::session_entry` (C1), `pi-core::config`
and `lockfile` (C7). TS references, read in full: `packages/coding-agent/src/core/session-manager.ts` (all 2,029
lines), `core/session-export.ts`, `core/session-cwd.ts`, `core/messages.ts`, `docs/session-format.md`,
`docs/sessions.md`, `docs/message-types.md`, `docs/compaction.md` (the context-building parts),
`packages/coding-agent/test/session-manager/*.test.ts`, `test/session-manager*.test.ts`, `test/session-*.test.ts`,
`test/fixtures/{large-session,before-compaction}.jsonl`.

## Goal

Pi's session store: the JSONL tree file, its migrations, branch and context projection, listing and search,
fork and clone, with files that the TypeScript pi opens unchanged and vice versa.

## Deliverables (`pi-core/src/session/`)

- `entries.rs`: `assert_valid_session_id`, id generation (8-hex with UUID fallback as TS), `parse_session_entries`
  (BOM, blank lines, invalid lines handled as TS does: read `load-entries.test.ts` and `session-file-invalid.test.ts`),
  `migrate_session_entries` (v1 linear to v2 tree, v2 `hookMessage` to v3 `custom`, in place),
  `get_latest_compaction_entry`, `session_entry_to_context_messages`, `build_context_entries`,
  `project_context_entry`, `build_session_projection`, `build_session_context`.
- `files.rs`: `get_default_session_dir(cwd, agent_dir)` (the `--<path>--` encoding), `load_entries_from_file`,
  `find_most_recent_session`, session listing with `SessionInfo` (created, modified, message count, first message,
  all-messages text for search) and `SessionListProgress`, the file name `<timestamp>_<id>.jsonl` with the same
  timestamp format, append-only writes (`appendFileSync` semantics: one line per entry, flushed per write),
  the write lock or lack of it exactly as TS has it (document what TS does about concurrent writers).
- `manager.rs`: `SessionManager` with every public method of the TS class (`create`, `open`, `in_memory`,
  `continue_recent`, `new_session`, `get_cwd`, `get_session_dir`, `get_session_id`, `get_session_file`,
  `get_leaf_id`, `get_leaf_entry`, `get_entry`, `get_label`, `get_branch`, `get_header`, `get_entries`,
  `get_tree`, `append_message`, `append_thinking_level_change`, `append_model_change`, `append_usage`,
  `append_compaction`, `append_branch_summary`, `append_custom_entry`, `append_custom_message_entry`,
  `append_context_edit`, `append_label`, `append_session_info`, `set_leaf`, `reset_leaf`, `branch`,
  `branch_with_summary`, `fork`, `clone`, `import_from_jsonl`, `get_session_name`, `set_session_name`,
  `list_sessions`, `delete`, `get_entry_count`, and the rest); implements `pi_sdk::ReadonlySession`.
- `export.rs`: `session-export.ts` (serialize the current branch to JSONL). `cwd.rs`: `session-cwd.ts`.

Rules: every line written goes through `pi_json::to_js_string` with the struct field order fixed in C1; ids and
timestamps come from `pi_json`; the header is written first and never rewritten except by the operations that TS
rewrites it in (check `fork`, `clone`, `set_session_name`).

## Acceptance

- Every test under `test/session-manager/` and every `session-*` test in `test/` ported case by case.
- Golden: `rust/fixtures/sessions/migration/` holds `before-compaction.jsonl` migrated by TS (generate with a
  node script that calls `migrateSessionEntries` and writes the result; commit script and output); the Rust
  migration output is byte-identical.
- Golden: for `large-session.jsonl`, `build_context_entries` and `build_session_context` from the leaf produce
  the same entry ids and message list as TS (generate the expected JSON with a node script; commit both).
- Cross-open: a session created and written by Rust (10 entries, a branch, a label, a context edit, a
  compaction) is opened by the TS `SessionManager` in a node test script and yields the same tree and context;
  this script is committed under `rust/fixtures/sessions/cross-open/` and run by a Rust test when `node` and
  `node_modules` are available (skipped with a message otherwise).
