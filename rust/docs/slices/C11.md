## Goal

Pi's compaction: threshold and overflow triggers, cut points, the summarization request and its retry, extension
overrides, and branch summaries on tree navigation, writing the same entries the TypeScript pi writes.

## Deliverables (`pi-core/src/compaction/`)

- `compaction.rs`: `CompactionSettings` with `DEFAULT_COMPACTION_SETTINGS`, `calculate_context_tokens`,
  `get_last_assistant_usage`, `estimate_context_tokens`, `estimate_projected_context_tokens`, `should_compact`,
  `estimate_tokens`, `find_turn_start_index`, `find_cut_point` (`CutPointResult`, the turn-boundary and
  token-budget rules), `get_summarization_failure`, `prepare_compaction` (`CompactionPreparation`),
  `generate_compaction_summary` (the summarization request over `pi-ai` with `SUMMARIZATION_SYSTEM_PROMPT`,
  structured summary format, reasoning handling per `compaction-summary-reasoning.test.ts`), `CompactionResult`,
  `CompactionDetails`, the `systemMessage` checkpoint captured at the boundary.
- `branch_summarization.rs`: `collect_entries_for_branch_summary`, `prepare_branch_entries` with the token
  budget, `generate_branch_summary`, `BranchSummaryResult`, `BranchSummaryDetails`.
- `utils.rs`: `FileOperations` tracking (`extract_file_ops_from_message`, `compute_file_lists`,
  `format_file_operations`), `serialize_conversation`, nested-call serialization.
- In `agent_session/compaction.rs`: `compact(custom_instructions)`, `abort_compaction`, `abort_branch_summary`,
  `_check_compaction` after each assistant message, `_run_auto_compaction` for `threshold` and `overflow` with the
  `willRetry` retry of the aborted turn, the `session_before_compact`/`session_compact`/`session_compact_failed`
  hooks with extension-provided compactions, `compaction_start`/`compaction_end` events, the summarization retry
  events (`summarization_retry_scheduled`/`attempt_start`/`finished`) shared with branch summaries,
  `set_auto_compaction_enabled`, the queued-input behaviour during auto-compaction, `is_compacting`.
