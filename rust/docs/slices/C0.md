# Slice C0: workspace bootstrap, `pi-json`, xtask, the gate

Read first: `rust/docs/conventions.md`, `rust/docs/slices.md`, `packages/env/daemon/Cargo.toml`,
`scripts/check-pinned-deps.mjs`, `packages/ai/src/utils/uuid.ts`, `packages/chord/src/json.ts`.

## Goal

The Cargo workspace every later slice builds into, the gate every slice must pass, and `pi-json`: the one place
that turns values into bytes the TS implementation would have written.

## Deliverables

### 1. Workspace

- `rust/Cargo.toml`: `[workspace]` with `resolver = "3"`, `members` listing every crate below, `[workspace.package]`
  (`edition = "2024"`, `license = "MIT"`, `publish = false`, `rust-version`), `[workspace.dependencies]` with every
  version `=`-pinned, `[workspace.lints]` (clippy: `all`, `pedantic` as warn with a short allow-list decided here,
  `unwrap_used` and `expect_used` warn, `missing_docs` warn via rustc), `[profile.release]` copied from the daemon
  (`lto = true`, `codegen-units = 1`, `strip = true`).
- `rust/rust-toolchain.toml`: `channel = "1.99.1"` (the installed stable), `components = ["rustfmt", "clippy"]`.
- `rust/rustfmt.toml`: `hard_tabs = true` (the repo uses tabs), `max_width = 120`.
- `rust/deny.toml`: advisories deny, licenses allow `MIT`, `Apache-2.0`, `Apache-2.0 WITH LLVM-exception`, `BSD-2-Clause`,
  `BSD-3-Clause`, `ISC`, `Zlib`, `Unicode-3.0`, `MPL-2.0` (file-level, list the crate when it first appears);
  `multiple-versions = "warn"`.
- Root `.gitignore`: add `rust/target/`.
- Crate skeletons, each with `Cargo.toml` (`workspace = true` fields, deps only on other workspace crates per the DAG
  below) and `src/lib.rs` (or `src/main.rs` for binaries) holding the file comment and nothing else:
  `crates/pi-json`, `pi-types`, `pi-telemetry`, `pi-schema`, `pi-ai`, `pi-agent`, `pi-mcp`, `pi-codemode`, `pi-tui`,
  `pi-sdk`, `pi-core`, `pi-interactive`, `pi-cli` (bin `pi`), `extensions/pi-ext-mcp`, `extensions/pi-ext-codemode`,
  `extensions/pi-ext-tool-search`, `pi-chord`, `pi-durable`, `pi-env-client`; `tools/pi-fake-provider` (lib + bin),
  `tools/pi-difftest` (bin), `tools/xtask` (bin).
- DAG (A <- B means B depends on A): `pi-json <- pi-types <- pi-ai <- pi-agent <- pi-sdk <- pi-core <- pi-interactive <- pi-cli`;
  `pi-schema <- pi-ai, pi-mcp, pi-codemode, pi-sdk, pi-durable`; `pi-telemetry <- pi-ai, pi-mcp, pi-core, pi-durable`;
  `pi-tui <- pi-sdk`; `pi-mcp <- pi-ext-mcp <- pi-cli`; `pi-codemode <- pi-ext-codemode <- pi-cli`;
  `pi-codemode <- pi-durable`; `pi-sdk <- pi-ext-tool-search <- pi-cli`; `pi-json <- pi-chord <- pi-durable <- pi-env-client`;
  `pi-json <- pi-fake-provider <- pi-difftest`. Rules that must hold forever: `pi-core` never depends on
  `pi-interactive`; `pi-sdk` never depends on `pi-core`; `pi-durable` never depends on `pi-core`; `pi-fake-provider`
  never depends on `pi-ai`.

### 2. `rust/check.sh`

Runs, in order, failing on the first error, with full output: `cargo fmt --all --check`,
`cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace`, `cargo deny check` (fails with
"install cargo-deny: cargo install cargo-deny" when the binary is missing), `cargo run -p xtask -- check-pins`,
`cargo run -p xtask -- verify-vendor`, `cargo build --release -p pi-cli && target/release/pi --version`.
`INSTA_UPDATE=no` exported. Must run from any cwd.

### 3. `xtask`

- `check-pins`: every entry of `[workspace.dependencies]` has an exact `=` version; every crate `Cargo.toml` declares
  external dependencies only with `workspace = true` (path dependencies on workspace crates are fine); fails listing
  each violation like `scripts/check-pinned-deps.mjs` does.
- `verify-vendor`: for every `rust/vendor/*/SHA256SUMS`, verifies the listed files (`sha256sum -c` semantics, in
  Rust). The directory is empty in C0; the command must succeed on an empty set.
- `hydrate-check`: fails with "run `npm run hydrate:model-data`" when `packages/ai/src/providers/data/` has no
  `*.json`; succeeds otherwise. Not part of `check.sh` yet (used from C3).

### 4. `pi-json`

Files: `src/lib.rs` (re-exports), `src/stringify.rs`, `src/number.rs`, `src/time.rs`, `src/uuid.rs`.

- `pub type JsonValue = serde_json::Value;` with `serde_json` features `preserve_order` and `float_roundtrip`.
- `pub fn to_js_string(value: &JsonValue) -> String`: byte-identical to `JSON.stringify(value)` in Node 26:
  no whitespace; object keys in insertion order; strings escaped as `JSON.stringify` does (`"` `\\` `\b` `\f` `\n`
  `\r` `\t`, other control characters below 0x20 as `\u00XX` lowercase hex, nothing else escaped: `/`, non-ASCII,
  U+2028 and U+2029 are written raw); numbers as `Number.prototype.toString`: integers with magnitude below 1e21
  without exponent or fraction, otherwise the shortest round-trip digits in JS exponent form (`1e+21`, `1e-7`,
  `1.5e+300`, `-0` prints `0`); `NaN` and infinities cannot occur in `serde_json::Value`.
  `pub fn to_js_string_pretty(value: &JsonValue, indent: usize) -> String` matching `JSON.stringify(value, null, indent)`
  (empty arrays and objects print as `[]` and `{}`).
- `pub fn js_number_to_string(f64) -> String` exposed separately (`number.rs`), implemented with `ryu` shortest digits
  and the JS formatting rules (ECMA-262 Number::toString, section 6.1.6.1.20).
- `pub fn iso_ms(SystemTime) -> String` = `Date.prototype.toISOString` (`YYYY-MM-DDTHH:mm:ss.sssZ`, year outside
  0..=9999 in the six-digit signed form) and `pub fn parse_iso_ms(&str) -> Option<SystemTime>`; use `jiff`.
- `pub fn uuid_v4() -> String` and `pub fn uuid_v7(timestamp_ms: Option<u64>) -> String`: a port of
  `packages/ai/src/utils/uuid.ts` including its monotonic sequence behaviour (process-wide state behind a mutex) and
  the `RangeError` cases as an error enum. Lowercase hex, hyphenated.

### 5. Fixture corpus

`rust/fixtures/json/gen.mjs` (plain node, no dependencies): generates 5,000 random JSON values covering nested
objects and arrays, strings with every escape class and non-BMP characters, integers at the `2^53` and `1e21`
boundaries, floats across exponents (`5e-324`, `1e-7`, `123456789012345680000`, `0.1+0.2`), negative zero, and
writes `rust/fixtures/json/cases.jsonl` with one record `{"value": <v>, "compact": "<JSON.stringify(v)>", "pretty2": "<JSON.stringify(v,null,2)>"}`
per line, plus 200 extra number-only cases in `numbers.jsonl` (`{"n": <float>, "s": "<String(n)>"}`), with a fixed
seed so the output is reproducible. Commit the generated files. Tests in `pi-json` read them and assert equality.

## Acceptance

- Every `cases.jsonl` and `numbers.jsonl` record passes.
- `cargo tree -p pi-cli` shows the DAG above and nothing else; `cargo build -p pi-sdk` does not build `pi-core`.
- Report lists every workspace dependency added with its version and why.
